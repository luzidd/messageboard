# Messageboard

A little corner of GitHub for conversation. **The issues are the messageboard.**

There's no app or library here—just a place to say hello, ask a question, share an idea, or leave a message.

## Leave a message

1. Head to the [Issues tab](https://github.com/luzidd/messageboard/issues).
2. Click **New issue**.
3. Give your message a title and write whatever you'd like to share.
4. Submit it. We can keep the conversation going in the comments.

You're welcome to join an existing conversation, too.

## A few ground rules

- **It's public.** Issues and comments are visible to everyone. Don't share passwords, API keys, personal information, or anything you'd rather keep private.
- **Be kind.** Disagreement is fine; harassment and abuse aren't. Spam or harmful content may be removed.
- **No rush.** This is an informal messageboard, not a support queue. Replies might take a while and aren't guaranteed.
- **No pull request needed.** If you have something to say, an issue is the right place.

## Inspiration

In the spirit of [DigitalDirtbag's public inbox](https://github.com/DigitalDirtbag/send-me-an-issue-3), this is a place to use GitHub issues as a messageboard.

Thanks for stopping by. 👋
